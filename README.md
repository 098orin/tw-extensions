# Turbowarp extensions
## appfsman.js
JavaScriptのFile System Access APIをTurbowarpから簡単にあるかえるようにする拡張機能。
* Chrome, edge などの File System Access API をサポートしている環境でのみ動作。
* サンドボックスなし必須

## b64_hex.js
base64をhexにしてくれる拡張機能。

## bitops.js
簡単なbit演算ができる拡張機能。

## file_loader.js
ファイルをhexで読み込む拡張機能。Turbowarpではhexで読み込めないので作った。
* サンドボックスなし必須

## riff_ext.js
RIFF形式のファイルを扱うのを簡単にするための拡張機能。
